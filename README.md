## URL Parameters

### `lang` — Start language
Sets the language on load. Default is Dutch (`nl`).

| Example | Result |
|---|---|
| `?lang=en` | Opens in English |
| `?lang=nl` | Opens in Dutch |

### `tags` — Filter projects
Scrolls to the projects section and activates a tag filter.

| Example | Result |
|---|---|
| `?tags=3D%20cad` | Shows only 3D CAD projects |
| `?tags=API` | Shows only API projects |
| `?tags=ARDUINO` | Shows only ARDUINO projects |
| `?tags=ELECTRONICS` | Shows only 3D CAD projects |
| `?tags=PCB` | Shows only PCB projects |
| `?tags=VIDEO` | Shows only VIDEO projects |
